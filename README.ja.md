# 吉野デジタルマップ (kidssafe-yoshino)

このリポジトリには、福井県越前市吉野地区の地域の安全と魅力発見を目的としたインタラクティブマップ、**吉野地区発見マップ**のデータとコードが含まれています。

このマップは、[Code for FUKUIのKidsSafeプロジェクト](https://github.com/code4fukui/kidssafe/)を利用して構築されており、地域の方々がシンプルなCSVファイルを使って簡単に更新できるように設計されています。

## 主な機能

- **インタラクティブマップ**: 地域の方々が投稿したおすすめスポット、安全に関する場所（AEDなど）、地元のランドマークを閲覧できます。
- **CSVベースのデータ管理**: すべてのポイントデータは、ExcelやNumbersなどの表計算ソフトで編集可能なシンプルなCSVファイル（例: [`aed.csv`](aed.csv)）で管理されます。
- **ルートのオーバーレイ表示**: 通学路（`tsugakuro.geojson`）などの経路やルートのGeoJSONデータを表示します。
- **詳細情報**: マップ上のポイントをクリックすると、説明文、写真、Googleストリートビューへの直接リンクなどの詳細情報を確認できます。
- **キーワード絞り込み**: 検索バーに文字を入力することで、表示されるポイントを即座に絞り込むことができます。
- **モバイル対応**: どのデバイスでも快適に動作するレスポンシブデザインを採用しており、スマートフォンのホーム画面に追加してすぐにアクセスできます。
- **多言語対応**: マップのインターフェースを他の言語に切り替えることができます。

## マップデータの管理方法

このリポジトリ内のデータファイルを更新することで、誰でもマップの編集に参加できます。

### 既存データの更新

1. 変更したいデータファイル（例: [`yoshino_R7tanken_07shisetsu.csv`](yoshino_R7tanken_07shisetsu.csv)）を開きます。
2. 「Download raw file」ボタンをクリックして、パソコンに保存します。
3. 表計算ソフトでファイルを開き、編集します。
4. 編集したファイルをリポジトリにアップロードして上書きし、マップを更新します。

### 新しいデータレイヤーの追加

1. [`template.csv`](template.csv)ファイルをダウンロードします。
2. 表計算ソフトで開き、新しいポイントを追加します。各ポイントには少なくとも `lat`（緯度）と `lng`（経度）が必要です。必要に応じて、その他の列（例: `名称`、`説明`、`写真`）を追加できます。
3. わかりやすい名前（例: `historic_sites.csv`）を付け、CSV形式でファイルを保存します。
4. [`index.csv`](index.csv)ファイルをダウンロードします。
5. `index.csv` に新しい行を追加して新しいデータレイヤーを登録し、ファイル名、マップ上に表示する名前、デフォルトのアイコンを指定します。
6. 新しいCSVファイルと更新した `index.csv` の両方をリポジトリにアップロードします。

### カスタムアイコンの追加

1. アイコンをPNG画像として準備し、一意でシンプルなファイル名（例: `shrine_icon.png`）を付けます。
2. このリポジトリ内の [`icon`](icon) フォルダに画像ファイルをアップロードします。
3. データのCSVファイル、または [`index.csv`](index.csv) の該当するデータポイントの `icon` 列に、新しいファイル名を入力します。
4. 変更をコミットします。これでマップにカスタムアイコンが表示されるようになります。
